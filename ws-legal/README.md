# WordSurge — legal pages

Public hosting for the privacy policy, terms and support page of the WordSurge Android game
(`ai.arena.wordsurge`), served with GitHub Pages.

After enabling **Settings → Pages → Deploy from a branch → main / (root)**, the pages are at:

- `https://<owner>.github.io/wordsurge-legal/privacy-policy.html`  ← paste into Google Play Console
- `https://<owner>.github.io/wordsurge-legal/terms.html`
- `https://<owner>.github.io/wordsurge-legal/support.html`

Source of truth is `legal/` in the main `wordsurge` repository; copy the files here when they change.
